# 聲音快捷切換

使用 Avalonia UI 製作的喇叭／耳機一鍵切換工具。

按下主按鈕後會固定依序執行：

1. 檢查目前輸出是否靜音；若是，先解除靜音。
2. 將目前系統輸出音量調整至 0%。
3. 切換 macOS 預設輸出裝置（CoreAudio）。
4. 若新輸出裝置為靜音，先解除靜音。
5. 將新輸出裝置音量調整至 33%。

## 執行

```bash
dotnet restore --ignore-failed-sources
dotnet run
```

目前平台支援：

- macOS：使用 CoreAudio 列舉與切換輸出裝置，使用系統音量控制設定音量。
- Linux：使用 `pactl`，相容 PulseAudio 與 PipeWire 的 PulseAudio 相容層。

裝置名稱與系統傳輸資訊會自動辨識「喇叭」、「耳機」及「藍牙」；「藍牙」是獨立的連線方式，因此藍牙裝置可以同時被辨識為喇叭或耳機。裝置清單中的「藍牙」核取方塊可手動修正自動辨識結果，選擇會在重新整理後保留。macOS 回傳的「揚聲器」名稱會在介面中顯示為「喇叭」。若名稱無法辨識，會列為其他輸出，仍可作為切換候選。切換前請確認系統中已連接至少兩個輸出裝置。

「預設裝置」區域可分別指定預設喇叭、預設耳機、預設藍牙喇叭及預設藍牙耳機。一鍵切換時會優先使用目前輸出所屬角色的對應目標；未指定角色時則使用自動辨識結果。
